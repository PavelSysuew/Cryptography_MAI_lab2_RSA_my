## Сборка и запуск

Для пресета `debug` нужны CMake 3.25 или новее, Ninja, компилятор с поддержкой C++20 и заголовки Boost. Команды выполняются из корня проекта.

```bash
cmake --preset debug
cmake --build --preset debug --target RSA
./build/debug/RSA
```

Пункт `1` главного меню открывает математические функции. Пункт `5` завершает программу.

### Тесты

```bash
cmake --build --preset debug --target test_RSA
ctest --preset debug
```

- `ctest --preset debug -N` — показать список тестов без запуска.
- `ctest --preset debug -V` — запустить тесты и показать вывод всех проверок.
- `./build/debug/test_RSA` — запустить тестовую программу напрямую и увидеть цветные метки в терминале.

После правок в `.cpp` и `.hpp` достаточно повторить сборку нужной цели. Если проект перенесли и CMake сообщает о старом пути в кэше, выполни `cmake --fresh --preset debug`.
